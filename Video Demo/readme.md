Purpose

This video demonstrates the complete functionality of the DocSpot platform, built using the MERN Stack (MongoDB, Express.js, React, Node.js). It walks through all major use cases from a scenario-based perspective.

Covered Features

1. Homepage Overview  
   - Clean, responsive design  
   - Navigation to login/register  

2. User Registration & Login  
   - Sign up as Patient, Doctor, or Admin  
   - Role-based dashboards

3. Doctor Search & Filtering  
   - Search by specialization, location, availability  

4. Appointment Booking  
   - Select doctor, choose date/time  
   - Upload reports or medical documents  

5. Confirmation Process  
   - Doctor confirms/rejects request  
   - Real-time status tracking  

6. Doctor Dashboard  
   - View appointments  
   - Confirm/reschedule/cancel  

7. Admin Panel  
   - Approve doctor applications  
   - Monitor system activity  

8. Appointment History  
   - Patients can view past & upcoming appointments
